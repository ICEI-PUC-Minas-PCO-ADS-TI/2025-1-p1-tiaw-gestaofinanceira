## User flow

Fluxo de usuário (user flow) é uma técnica que permite ao desenvolvedor mapear todo o fluxo de navegação do usuário na aplicação. Essa técnica serve para alinhar os caminhos e as possíveis ações que o usuário pode realizar junto com os membros da equipe

![User flow](images/projeto-interface/user-flow.jpg)

## Wireframes

São protótipos usados no design de interface para sugerir a estrutura de um site web e seu relacionamento entre suas páginas, um wireframe web é uma ilustração que mostra o layout dos elementos fundamentais na interface

##### TELA CRIAR CONTA

Tela onde o usuário pode criar uma nova conta, informando nome, e-mail, senha e confirmação de senha. Possui botão para finalizar o cadastro e link para voltar à tela de login. O objetivo é permitir que novos usuários se registrem de forma simples e rápida

![Tela para criar a sua conta](images/projeto-interface/wireframe/piCriarConta.png)

##### TELA FAZER LOGIN

Tela para o usuário realizar login na sua conta já existente, inserindo e-mail e senha. Inclui opção de lembrar login, botão para acessar a conta e link para recuperação de senha caso o usuário tenha esquecido. Facilita o acesso seguro e rápido ao sistema

![Tela para realizar login](images/projeto-interface/wireframe/piLogin.png)

##### TELA DE INÍCIO E VISÃO GERAL

Tela principal após o login, onde o usuário acessa as principais funções do sistema. Exibe o saldo atual, receitas e despesas do mês, além das transações mais recentes. Possui botões para adicionar nova receita ou despesa e atalhos para acessar relatórios detalhados. Ajuda o usuário a ter uma visão clara e rápida de sua situação financeira

![Tela inicial e de visão geral](images/projeto-interface/wireframe/piVisaoGeralConta.png)

##### TELA DE RELATÓRIOS

Tela onde o usuário visualiza relatórios financeiros por mês, podendo acompanhar a evolução das receitas e despesas ao longo do tempo. Permite selecionar o mês desejado e visualizar gráficos de desempenho financeiro, facilitando o acompanhamento e a tomada de decisões

![Tela para visualizar relatórios das finanças](images/projeto-interface/wireframe/piRelatorioGeral.png)

Relatório de receitas por categoria no mês, exibindo um gráfico que mostra quanto foi recebido em cada categoria (ex: salário, investimentos, etc). Ajuda o usuário a identificar as principais fontes de receita

![Tela para Vizualizar gráfico de receitas por categorias](images/projeto-interface/wireframe/piReceitaPorCategoria.png)

Relatório de gastos por categoria no mês, apresentando um gráfico que detalha quanto foi gasto em cada categoria (ex: alimentação, transporte, lazer). Auxilia o usuário a entender para onde está indo seu dinheiro e a planejar melhor seus gastos

![Tela para Vizualizar gráfico de despesa por categoria](images/projeto-interface/wireframe/piDespesaPorCategoria.png)
